Since September 2023 I have worked as a Senior iOS Developer on contract at HiQ Gothenburg, working remotely from Sweden. My projects focus on navigation and connected electric vehicles, using modern Apple technologies and CarPlay.
<!--more-->

## Project 1: EV navigation companion app

I joined a large team building an electric-vehicle navigation app for a global automotive OEM. Working directly with the manufacturer, we connected the app to the car's ecosystem. That let us add battery-consumption estimates, estimated charging costs along planned routes and push notifications for specific vehicle states.

We used HERE SDK for maps, the Iternio EV Planning API for routing and CarPlay integration. Apart from the code required by CarPlay, the app was built entirely in SwiftUI. Networking and some business logic used Kotlin Multiplatform Mobile (KMM) to share code with Android.

Technologies: Swift, SwiftUI, Kotlin, KMM, CarPlay, HERE SDK and the Iternio EV Planning API.

## Project 2: Connected-vehicle companion app (current)

I am currently working on a project for an EV manufacturer startup in Saudi Arabia through HiQ and WirelessCar. I work across the native iOS app, building features in Swift and SwiftUI and connecting them to shared modules and connected-vehicle services.

I built and delivered the Godot-based 3D vehicle experience on my own. This included integrating the Godot runtime into the iOS app and building an OpenAPI-based bridge between Swift and Godot to display live vehicle data.

I use agentic tooling and AI-first development with Codex and MCP.

Technologies: Swift, SwiftUI, Godot 4, GDScript and OpenAPI.
